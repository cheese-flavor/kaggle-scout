Kaggle Scout v0.10.3

1. 바탕화면의 Kaggle Scout 바로가기 또는 run.bat를 실행합니다.
   실행 파일: dist\KaggleScout\KaggleScout.exe
2. 처음 열리는 연결 화면에서 Kaggle API 토큰을 입력합니다.
   기존 kaggle.json 파일을 선택해도 됩니다.
   토큰을 채팅이나 GitHub에 올리지 마세요.
3. 기본 프로필을 확인한 후 '설정 저장하고 대회 확인'을 누릅니다.

기본값: Python / SQL, RTX 5060 Ti 16GB, 유료 API 없음.
설정에서 관심 분야와 환경을 변경할 수 있습니다.
프로그램 자체는 AI API를 호출하지 않습니다.

창을 닫으면 트레이에서 계속 실행됩니다.
완전히 종료하려면 트레이 아이콘을 우클릭하여 종료를 누르세요.
PC가 꺼져 있거나 앱이 종료되어 있으면 확인하지 않습니다.

다른 PC에서는 dist\KaggleScout 폴더 전체를 옮기고 다시 연결합니다.
폴더 안의 _internal 폴더를 실행 파일과 함께 유지하세요.

설치 파일은 AppData\Local\Programs\KaggleScout에 저장됩니다.
인증 정보와 개인 기록은 AppData\Local\KaggleScout에 분리하여 저장됩니다.
인증은 기본으로 이번 실행 동안 유지됩니다. 저장을 선택하면 Windows 현재 사용자 계정으로 암호화합니다.
프로그램 MIT와 Qt/PySide6 LGPLv3 안내는 LICENSE, THIRD-PARTY.md와 licenses 폴더에서 확인할 수 있습니다.

실제 계정 토큰 연결 후 수집 확인은 최초 실행 시 필요합니다.
선택 설치: install.ps1을 실행하면 바탕화면과 시작 메뉴 바로가기가 생성됩니다.
상세 설명과 제한사항: README.md
